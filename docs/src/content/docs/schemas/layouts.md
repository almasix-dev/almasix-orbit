---
title: Layouts
description: Structure schemas with Grid, Flex, and related layout components.
---

Use layout components from `almasix.orbit.schemas` inside any schema (forms, infolists, pages).

| Component | Role |
|-----------|------|
| `Grid` | Responsive columns, `column_span`, dense/gap |
| `Flex` | Flex row/column with grow + breakpoints |
| `Section` | Bordered section with heading/description |
| `Fieldset` | Native fieldset + legend |
| `Group` / nested `schema()` | Fuse child components |

See [Schemas overview](/schemas/overview/) for examples.
