**Orbit brings Filament's power to Almasix.**

Build admin panels, resources, forms, tables, actions, infolists, notifications, widgets, and query builders with a Filament 5.x-style fluent API — rendered as semantic `.or-*` CSS on Conduit + Alpine.js.

Install with `pip install almasix-orbit`, then see [Getting started](/getting-started/) and the [parity matrix](/parity/).
