**Orbit** is how you build admin panels in [Almasix](https://docs.almasix.com/) without leaving Python.

Declare a panel. Point it at resources. Describe forms, tables, and actions with a fluent API. Orbit renders semantic `.or-*` markup on **Conduit** + **Alpine.js** — server is the source of truth, the browser stays snappy.

:::tip[A nod to Filament]
Orbit stands on the shoulders of [Filament](https://filamentphp.com/) — the panel / resource / form / table vocabulary was a huge inspiration. We’re our own package for the Almasix/Python world, with our own rendering stack and DX. Same *idea*, our *house*.
:::
